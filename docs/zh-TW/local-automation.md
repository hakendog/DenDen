# Bixby 與 Tasker

DenDen 可以直接接收手機上的 Bixby 日常行程與 Tasker 自動化。這種方式不需要 Firebase、DenDen 配對碼、電腦端工具或網路。

第一次開啟 DenDen 時，在配對畫面選擇「只使用本機自動化」。之後如果要接收 AI 助理的遠端通知，仍可從 DenDen 設定中選擇「立即配對」。

Bixby 與 Tasker 建立的訊息都會保存在 DenDen 收件匣。即使 Android 沒有顯示通知，仍可回到 DenDen 查看紀錄。

## Samsung Bixby

1. 在 Samsung 手機開啟「模式與日常行程」。
2. 建立新的日常行程，設定觸發條件。
3. 在執行動作中選擇 DenDen。
4. 選擇安靜訊息、一般通知或警報。

Bixby 動作使用固定內容，不需要輸入標題或訊息。警報預設響鈴 30 秒。

如果「模式與日常行程」沒有列出 DenDen，請先更新 DenDen 與手機系統。部分 Samsung 手機或 One UI 版本可能不支援第三方應用程式動作。

## Tasker

DenDen 已內建 Tasker 外掛，不需要安裝其他搭配應用程式。

1. 在 Tasker 的工作中新增動作，選擇「DenDen 通知或警報」。
2. 選擇安靜訊息、一般通知或警報。
3. 填寫標題、訊息與響鈴秒數。
4. 如有需要，可在文字欄位使用 `%title`、`%message`、`%duration` 等 Tasker 變數。
5. 儲存動作並執行一次測試。

標題最多 200 字，訊息最多 1000 字，響鈴時間可設為 0 到 300 秒。輸入 0 會使用預設的 30 秒。

清除 DenDen 資料或重新安裝後，請重新開啟並儲存既有的 Tasker 動作，讓它重新取得執行權限。

## 通知沒有出現時

先回到 DenDen 收件匣確認訊息是否存在。如果訊息已保存但 Android 沒有顯示通知，請檢查通知權限、對應的通知類別、勿擾模式與電池最佳化設定。

警報還會受到全螢幕通知權限與手機廠牌背景限制影響。更多處理方式見[疑難排解](troubleshooting.md)。
