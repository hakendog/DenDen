# 通知、圖片與備份

初次配對後，可以請 AI 助理安裝日常通知功能、更換 DenDen 圖片、匯出或匯入設定，以及更新手機 App。設定助手會在變更前顯示摘要。

## 安裝日常通知功能

如果初次安裝時略過日常通知功能，之後仍可請設定助手補裝。你可以安裝到 AI 助理平常使用的位置、指定其他位置，或只查看目前狀態。

將下面整段內容複製並貼給該 AI 助理：

```text
請先根據以下 DenDen 安裝引導載入設定助手，再為目前的 AI 助理安裝 DenDen 日常通知功能：

https://raw.githubusercontent.com/hakendog/DenDen/26a9298d199d4c65b547288d36166a628d80b628/docs/agent-install.md
```

安裝時可以重新選擇哪些工作結果需要通知。日常通知功能只能傳送通知，不能管理 Google 專案、重新配對手機或更換圖片。

如果指定位置已經有不同內容，設定助手不會直接覆蓋，會先說明差異並詢問如何處理。

## 更換 DenDen 圖片

你可以隨時改用內建圖片、產生新圖片、依條件產生圖片，或匯入透明背景的 PNG 圖片。更換圖片不需要重新配對手機。

設定助手會先提供預覽。確認後，新的圖片會送到已配對的手機，並由各支手機分別接受更新。未完成更新的手機可以之後再處理。

使用外部圖片服務前，設定助手會先說明需要上傳的素材。你也可以拒絕上傳，改用內建圖片或本機圖片。

## 匯出或匯入設定

設定助手可以處理兩種加密備份：

1. 一般通知設定，供日後恢復 DenDen 的基本設定。
2. DenDen 圖片管理備份，供日後更新或恢復圖片。

匯出時需要由你在電腦的輸入畫面中設定備份密碼；匯入時也由你直接輸入。AI 助理不會看到密碼。

一般設定備份不包含每台電腦各自的通知權限。把備份匯入新電腦後，仍需要另外授權該電腦。備份也不包含手機收到過的通知內容。

匯入前，設定助手會先說明哪些內容將被新增或取代。只有在你同意後才會寫入。

## 更新 DenDen

從 [GitHub 發布頁](https://github.com/hakendog/DenDen/releases)下載新版手機安裝檔，再使用 Android 直接覆蓋安裝。原有訊息、設定與配對資料會保留。

不要先解除安裝，也不要清除 DenDen 的應用程式資料。如果 Android 拒絕更新，先停止安裝並確認檔案來自 DenDen 的 GitHub 發布頁，再查看[疑難排解](troubleshooting.md)。

## 安全與使用提醒

- DenDen 配對碼、設定備份、私密設定資料夾與發送權限都不應分享或上傳。
- 密碼、Google 驗證碼與其他登入資料只在你自己的瀏覽器或電腦輸入畫面中輸入。
- 任何會改變專案、配對、圖片或電腦權限的操作，都應先有清楚的變更摘要。
- 完成設定、修復或新增裝置後，都要用測試通知確認結果。
- DenDen 不會替離線裝置保存等待傳送的通知。通知送出時若手機無法連線，手機恢復連線後也不會補收。
