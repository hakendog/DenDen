# 疑難排解

遇到安裝、配對或通知問題時，把下面整段內容複製並貼給能操作你電腦的 AI 助理：

```text
請先根據以下 DenDen 安裝引導載入設定助手，再檢查或修復 DenDen。我遇到的問題是：<請描述你看到的情況>

https://raw.githubusercontent.com/hakendog/DenDen/6aa2612514f69e4328da4781be84f3c54b510d1b/docs/agent-install.md
```

設定助手會先讀取目前狀態，不會直接重建專案、清除手機資料或覆寫設定。

## 設定無法開始

- 讓設定助手檢查 Git、Node.js 與 Google Cloud 工具。缺少工具時，先閱讀它顯示的用途與變更，再決定是否安裝。
- Google 要求接受 Firebase 條款時，依設定助手指示開啟 Firebase 網頁，只接受必要條款，不要另外啟用分析或其他產品。
- 如果指定的 Google 專案已連結帳務、用途不明或包含未知資源，請改用新的 DenDen 專用專案。
- 不要為了略過錯誤而貼出 Google 憑證、私鑰、設定檔或 DenDen 配對碼。

## DenDen 配對碼掃不出來

- 確認 DenDen 配對碼仍在設定助手顯示的期限內。
- 直接掃描設定助手在本機顯示的圖片，不要使用經過通訊軟體壓縮的截圖。
- 確認手機有網路與 Google Play 服務。手機不需要和電腦連接相同的 Wi-Fi。
- DenDen 配對碼可能外洩時，不要繼續使用，請設定助手重新建立整組配對。

## 已配對但沒有收到通知

依序檢查：

1. 開啟 DenDen，確認設定頁顯示已訂閱。
2. 確認手機可以連上網路，而且 DenDen 沒有遭 Android 強制停止。
3. 檢查 DenDen 的通知權限與各通知類別是否開啟。
4. 檢查勿擾模式、電池最佳化與手機廠牌的背景限制。
5. 回到 DenDen 收件匣，確認訊息是否已保存但未顯示系統通知。
6. 請設定助手重新傳送一則一般測試通知。

如果曾強制停止 DenDen，請親自重新開啟一次。

## 響鈴沒有出現

- 確認 DenDen 已取得通知與全螢幕通知權限。
- 檢查勿擾模式、音量、電池最佳化與背景限制。
- 確認你已明確允許該情況使用響鈴。未獲允許時，DenDen 會使用較低的提醒方式。

停止指定警報只會解除手機響鈴，不會停止 AI 助理的工作。

## Bixby 找不到 DenDen

先更新 DenDen 與 Samsung 系統，再重新開啟「模式與日常行程」。部分手機或 One UI 版本不支援第三方應用程式動作，此時可改用 Tasker。

## Tasker 動作失效

如果最近清除過 DenDen 資料或重新安裝，請在 Tasker 重新開啟並儲存既有動作。接著先執行一般通知測試，再檢查警報。

## 更新被 Android 拒絕

不要解除安裝舊版，也不要清除應用程式資料。先停止更新，確認 APK 來自 DenDen 官方 GitHub 發布頁，再向發布者確認簽章是否一致。

## 外觀沒有更新

回到 DenDen 前景，查看是否有等待確認的新外觀。新圖片只有在你預覽並接受後才會套用。如果傳送中斷，請設定助手續傳同一張圖片。

安全問題請依 [SECURITY.md](../../SECURITY.md) 回報。
